# COS-216-Netcentric-computer-systems
Project Overview
This portfolio showcases a comprehensive e-commerce website development project completed through four progressive practical assignments in COS 216. The project demonstrates full-stack web development skills, evolving from static HTML/CSS layouts to a dynamic, database-driven application with custom API integration.
Technologies Used: HTML5, CSS3, JavaScript, PHP, MySQL, AJAX, REST APIs
Development Progression
PA1: Foundation & Design
Focus: Static website structure and responsive design

Created a complete e-commerce website layout with professional navigation
Implemented responsive design patterns for Products, Deals, Cart, and Wishlist pages
Developed custom CSS styling with modern design principles
Built reusable component structure with consistent branding
Established proper file organization and web server deployment

Key Skills: HTML5 semantic elements, CSS Grid/Flexbox, responsive design, web server configuration
PA2: Dynamic Content & API Integration
Focus: JavaScript functionality and external API consumption

Integrated external Wheatley API for dynamic product data loading
Implemented real-time currency conversion across all pages
Built interactive search, filtering, and sorting functionality
Created loading animations and error handling for API requests
Developed image carousel and product detail views
Added client-side cart calculations and DOM manipulation

Key Skills: AJAX/XMLHttpRequest, JSON manipulation, DOM manipulation, asynchronous JavaScript, API consumption
PA3: Backend Development & Security
Focus: PHP API development and database design

Designed and implemented MySQL database schema with proper relationships
Created object-oriented PHP API with RESTful endpoints
Implemented secure user registration with password hashing and salt generation
Built API key authentication system for secure access
Developed SQL injection protection and input validation
Created modular PHP architecture with includes and configuration management

Key Skills: PHP OOP, MySQL database design, API development, security best practices, server-side validation, cURL integration
PA4: Complete Integration & User Management
Focus: Full-stack integration and persistent user data

Integrated custom PHP API with frontend JavaScript
Implemented secure login/logout with session management
Built persistent cart and wishlist functionality with database storage
Created order processing system with order tracking
Developed user preferences system with theme switching
Implemented cookie/localStorage for client-side data persistence
Added comprehensive order management and delivery tracking

Key Skills: Session management, user authentication, database relationships, state management, full-stack integration
Technical Achievements

Security Implementation: Proper password hashing, SQL injection prevention, API key authentication
Database Design: Normalized schema with foreign key relationships for users, products, carts, wishlists, and orders
API Architecture: RESTful design with consistent JSON responses and comprehensive error handling
User Experience: Responsive design, loading states, theme switching, and persistent user preferences
Code Quality: Object-oriented PHP, modular JavaScript, semantic HTML, and maintainable CSS
